# Security policy

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/OnishellT/agent-workbench-next/security/advisories/new).
Please do not open a public issue for a vulnerability.

The most useful reports concern authentication (the session cookie, token login, Origin and Host checks),
SSH host-identity verification, per-host isolation, the reverse-proxy trust model, and the handling of
credentials and conversation data. Vendored applications (Magpie, Sim) should also be reported upstream.

Only the latest release and `main` are supported.
