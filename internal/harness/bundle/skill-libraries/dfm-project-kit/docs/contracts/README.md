# DFM contract extracts

This folder contains narrow Markdown extracts of external contracts that once existed only as binary documents.

Use an extract for exact source fields after the short agent docs identify the contract. Retrieve the approved source from the team document system when legal or vendor wording matters.

## Files

- `sam-nextgen-digital-orders.md` covers the digital version 1.0 source. It does not cover the complete current physical, rental, refund, fulfillment, or outbox implementation.
- `sam-legacy-ecedoc.md` covers legacy SAM and MMS ECEDOC field shape.
- `shopify-sam-order-properties.md` covers SAM-driven Shopify metadata.

Start with `docs/architecture.md` and `docs/workers-and-messages.md`. Verify every extract against the current ticket, code, and tests.
