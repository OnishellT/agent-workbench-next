# Workbench

Dashboard de proyectos y agentes de dispositivos Linux.

[plan.md](plan.md) es la unica definicion de producto, tareas, reparto paralelo,
verificaciones y estado. Empezar por ese archivo y por AGENTS.md.

Prompt de ejecucion desde esta carpeta:

> Implementa lo que esta en plan.md con subagentes en paralelo y verifica el resultado.

Referencias tecnicas, solo cuando la tarea las necesite:

- [Operacion](docs/operations.md): comandos y topologia existentes.
- [Red](docs/network.md): observaciones del laboratorio, con fecha.
- [Fuentes](docs/research.md): documentacion primaria consultada.
- [Procedencia y licencias](NOTICE.md).
